📋 Supported Endpoints Cheat Sheet

Action Method Endpoint Path Description
Active Projects GET /admin/projectshell?Status=Active List active project shells
Company BP Catalog GET /admin/bps Master list of company Business Processes
Project BP Catalog GET /admin/bps/{project_number} BP catalog for specific project shell
Company BP Records POST /bp/records/ Query records for company BP (e.g. Vendor)
Project BP Records POST /bp/records/{project_number} Query records for project BP (e.g. Contract)
User Administration POST /admin/user/get Query Unifier user directory
Download Attachment POST /bp/record/file Download binary document attachments

Business Process (BP) Field Mapping

Standard Unifier BP REST API response schema:

  • 🔹 bp_model_name — The BP Unique Identifier / Model ID
  • 🔹 bp_name — The BP Display Name (Unique)
  • 🔹 studio_source — The BP Studio Type (simple, database, etc.)
  • 🔹 no_workflow — Boolean flag indicating non-workflow BPs
